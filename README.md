#  Networking Learning Journey

Welcome to my **Networking Learning Journey!**

I am a B.Sc. Computer Science graduate, currently learning Computer Networking from the basics and developing practical skills through daily study, hands-on exercises, and real-world networking scenarios.

My goal is to build strong networking fundamentals and prepare for entry-level opportunities in Network Support, NOC Engineering, and IT Support.

##  Learning Objectives

- Understand computer networking fundamentals.
- Learn OSI and TCP/IP models.
- Understand IP addressing and subnetting.
- Learn important networking protocols.
- Practise network troubleshooting.
- Gain hands-on experience with networking tools.
- Build practical networking projects.
